01 — About

Professional profile

I'm Shawon Haque, a Full Stack Developer working across the modern JavaScript ecosystem. I care about the whole path a product takes: how an interface feels to use, how the code is structured underneath it, and how quickly it loads for the people relying on it.

My work centres on React.js and Next.js on the frontend and Node.js on the server, supported by a solid foundation in semantic HTML, modern CSS and JavaScript. I build reusable components, keep concerns separated, and treat accessibility and performance as defaults rather than afterthoughts.

I'm early in my public track record and building it deliberately. Every project here is real, tested and shipped — I'd rather show a small body of honest work than a long list of things that don't exist.

How I work

  • Semantics first. Accessible, meaningful markup as the base layer.
  • Reusable by design. Components and styles that scale with a codebase.
  • Performance aware. Optimised assets and attention to Core Web Vitals.
  • Secure by default. Validated input and the principle of least privilege.
  • Consistency over intensity. Steady, reliable progress on real work.

03 — Projects

Selected work

A short, honest list — these are real repositories you can open and review today.

NEXORA

A full-stack knowledge platform for news, books, study resources and writing. The frontend is React 18 and TypeScript on Vite with Tailwind CSS — sixteen routed views including full-text search, light/dark theming and an authenticated admin area. The backend is Supabase and Postgres with a thirteen-table schema and Row Level Security on every table, so the database — not the client — decides who may read or write each row.
